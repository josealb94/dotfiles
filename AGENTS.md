# Dotfiles

Configuración portable de herramientas de desarrollo (macOS + Linux), con paquetes GNU Stow e
instalador interactivo. Ver `README.md` para la estructura y el uso.

## Idioma

Este repo se mantiene en español. Esto prevalece sobre cualquier default global que pida inglés.

- Commits en español, con formato Conventional Commits: `tipo(scope): resumen`
  (ej. `feat(herdr): tema y estilos del sidebar`).
- Documentación (`README.md`, `docs/`) en español.
- Comentarios y mensajes de los scripts en español.
